Outfit memory

Tap Love it or Skip it on the Today screen. The shuffle learns which pieces and pairings you like and shows rejected pairings less. Looks you love are saved.

Smart sort

On iPhone the AI steps use a lot of memory and can be slow or crash the page. Quick cleanup for backgrounds is recommended. Type recognition is off by default and experimental.

Reads each photo to fill in its color, pattern and type, for example "Navy hoodie", and moves photos you shot in Auto-sort to the right category. Color and pattern work instantly with no download. Recognizing the type uses an AI model that downloads once (about 150 MB), so use Wi-Fi. It can be wrong, so check the names and fix any in one tap. Anything you edit yourself is never overwritten.

Photo quality

Brightens dim photos, evens out a yellow or blue tint and adds a little contrast so every piece looks consistent. It runs on this phone and never uploads anything.

Photo cleanup

Removes the background so each piece sits cleanly on the outfit board. It runs on this phone. The first time it downloads a model of about 45 MB, so use Wi-Fi. Each photo takes a few seconds. Your original photos are always kept.

What I wear

Turn off anything you don't wear. Hidden categories are left out of outfits and the camera list. Photos you've already taken are kept.

Weather

Outfits use today's forecast to decide if you need a coat. Your city or location is sent to a free weather service (Open-Meteo) to get the forecast, and is saved only on this phone.
